# Script Movimento Balístico

Este projeto é um programa em Python que realiza diversos cálculos relacionados ao **movimento balístico** e ao **lançamento oblíquo**, utilizando conceitos básicos da Física.

O sistema funciona através de um menu interativo no terminal, permitindo ao usuário escolher diferentes operações, como cálculo de alcance horizontal, altura máxima, velocidade instantânea, tempo no ar, entre outros.

---

# Funcionalidades

O programa possui as seguintes funcionalidades:

1. Calcular a velocidade inicial nos eixos X e Y
2. Calcular o tempo que o objeto permanece no ar
3. Calcular a posição do objeto em determinado instante
4. Calcular a velocidade instantânea
5. Calcular a altura máxima atingida
6. Calcular o alcance horizontal
7. Calcular a velocidade antes de atingir o solo
8. Calcular a velocidade no instante da altura máxima
9. Calcular a distância horizontal em queda livre
10. Calcular movimento sem ângulo de lançamento
11. Encerrar o programa

# Como Executar

## 1. Instale o Python

Baixe e instale o Python(Windows):

https://www.python.org/downloads/

Para Debian e derivados:
```bash
sudo apt install python
```

Para Fedora/Red Hat Linux e derivados:
```bash
sudo dnf install python3
```

Para Suse e derivados:
```bash
sudo zypper in python3
```

Para Arch e derivados:
```bash
sudo pacman -S python
```

Para Gentoo:
```bash
sudo emerge -a dev-lang/python
```
